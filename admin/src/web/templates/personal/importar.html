Formato del archivo

La primera fila debe tener estos encabezados, separados por coma o punto y coma:

{{ columnas|join(',') }}
30111222,Ana,Pérez,Personal Fijo,Laboratorio De Guardia,General
40111333,Juan,López,Residente,,Vegetariano
  • tipo_personal: Personal Fijo o Residente.
  • sector: nombre del sector, obligatorio para Personal Fijo. Para residentes dejalo vacío.
  • menu: General, Vegetariano o Celíaco.

Cada fila se valida con las mismas reglas que el alta manual. Las filas con errores no se importan y se informan abajo con su motivo; el resto sí se importa.
